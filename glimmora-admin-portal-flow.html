2. Primary User Flow

The typical admin journey from login through daily operations

1

Login & Entry Entry Point

Admin logs in via /login with credentials. Redirected to /admin/dashboard. Auth state stored in Zustand. Session persists until logout.
Navigate to Dashboard
2

Dashboard — Command Center Overview

Institutional health at a glance: enrollment trends, retention, graduation rate, compliance score, faculty-student ratio. Shows recent compliance deviations and active semester info.
View Compliance Deviations Check Analytics View Active Courses View Current Semester
Connects to: /admin/compliance · /admin/analytics
3

Analytics — Deep Dive

KPI cards with trends, department performance comparison (bar chart), enrollment history (area chart), and department details table with GPA, retention, placement data.
View KPIs Compare Departments Historical Trends
4

Compliance — Regulatory Monitoring Critical

Overall compliance score gauge, framework scores (GDPR, FERPA), expandable compliance categories with pass/fail/warning checks, and deviation management with resolution workflow.
View Score Gauge Expand Categories Resolve Deviations View Audit Trail
Connects to: /admin/compliance/audit-trail
5

Audit Trail — Activity Tracking

System-wide log of all admin actions: timestamp, user, role, action type, resource, details, IP, outcome. Filterable by action type, role, and searchable.
Search Entries Filter by Action Filter by Role Paginate
6

Admissions — Application Management AI-Powered

Application pipeline visualization (Submitted → Under Review → Interview → Accepted/Rejected/Waitlisted), department capacity charts, monthly trends, demographics. Links to applications list and AI predictions.
Review Applications View AI Predictions Filter by Pipeline Stage View Demographics
Connects to: /admin/admissions/applications · /admin/admissions/predictions
7

Users & Roles — Access Management

User list with search/filter by role/status. Create single users, bulk import via CSV, view user details. Separate Roles & Permissions page with RBAC permission matrix.
Create User Bulk Import CSV View User Detail Manage Roles Download Template
Connects to: /admin/users/{id} · /admin/users/roles
8

Course Catalog — Curriculum Management

Course list with department/semester/status filters. Create courses (Draft → Active → Archived). Enroll students via search or CSV. Enrollment progress bars showing capacity.
Create Course Enroll Students Search & Filter View Enrollment
9

Semesters — Academic Calendar

Semester cards showing name, year, status (Upcoming/Active/Completed), date range, and course count. Create new semesters with date validation.
Create Semester View Status View Course Count
10

Budget & Resources — Financial Overview

Total budget, spent, remaining, utilization rate gauge. Monthly spend trend, department allocation vs actual spend comparison. Budget alerts by severity (overspend, approaching limit, anomaly).
View Utilization Monthly Trends Department Comparison Budget Alerts
11

AI Governance — Model Oversight AI

Overview of AI models: count, accuracy, bias scores. Links to Model Registry (detailed model cards with fairness metrics) and Bias Reports (demographic audits with recommendations).
Model Registry Bias Reports Override Log
Connects to: /admin/ai-governance/models · /admin/ai-governance/bias-reports
12

Credentials — Digital Credential Management

Issue, manage, and revoke student credentials (Degree, Certificate, Badge, Transcript). Search/filter by type and status. Revocation requires documented reason.
Issue Credential Revoke Credential Search & Filter
13

Reports — Institutional Reporting

Browse report templates (Compliance, Enrollment, Financial, Performance, Custom). Generate reports with template-specific parameters. Download completed reports. Monitor generation status.
Generate Report Download PDF/Excel Monitor Status
14

Settings — Institution Configuration

General settings (name, timezone, locale, branding). Data sharing policies (ministry sharing, anonymization, public profile). Data retention policies. Color theme customization.
Save Settings Configure Branding Data Sharing Toggles Retention Policies

5. CRUD Operations by Page

Users & Roles

/admin/users
Operations
  • Create: Single user (dialog) + Bulk CSV import
  • Read: User list with search/filter/pagination, User detail page
  • Update: Edit user role, department, status
  • Delete: N/A (status change to Suspended instead)
API Endpoints
GET /api/admin/users GET /api/admin/users/{id} POST /api/admin/users POST /api/admin/users/bulk PATCH /api/admin/users/{id}

Course Catalog

/admin/courses
Operations
  • Create: New course (dialog with department/semester/faculty selection)
  • Read: Course list with multi-filter, enrollment progress bars
  • Update: Course status (Draft → Active → Archived)
  • Enroll: Add students via search or CSV
API Endpoints
GET /api/admin/courses POST /api/admin/courses POST /api/admin/courses/{id}/enroll

Semesters

/admin/semesters
Operations
  • Create: New semester with date validation
  • Read: Semester cards with status/dates/course count
  • Update: Status transitions (Upcoming → Active → Completed)
API Endpoints
GET /api/admin/semesters POST /api/admin/semesters

Credentials

/admin/credentials
Operations
  • Create: Issue credential (Degree/Certificate/Badge/Transcript)
  • Read: Credential list with type/status filters
  • Revoke: Revoke active credential (requires documented reason)
API Endpoints
GET /api/admin/credentials POST /api/admin/credentials POST /api/admin/credentials/{id}/revoke

Compliance

/admin/compliance
Operations
  • Read: Compliance score, framework scores, categories, deviations
  • Update: Resolve deviations (requires resolution description)
API Endpoints
GET /api/admin/compliance/pulse GET /api/admin/compliance/deviations PATCH /api/admin/compliance/deviations/{id}

Reports

/admin/reports
Operations
  • Create: Generate report from template with custom parameters
  • Read: Browse templates, view generated reports list
  • Download: Download completed reports (PDF/Excel)
API Endpoints
GET /api/admin/reports/templates GET /api/admin/reports/generated POST /api/admin/reports/generate

Settings

/admin/settings
Operations
  • Read: Current institution settings
  • Update: General, data sharing, retention, branding
API Endpoints
GET /api/admin/settings PATCH /api/admin/settings

AI Governance

/admin/ai-governance
Operations
  • Read: Model overview, model registry, bias reports, override log
  • Navigate: Models detail, bias reports detail
API Endpoints
GET /api/admin/ai-governance/overview GET /api/admin/ai-governance/models GET /api/admin/ai-governance/bias-reports GET /api/admin/ai-governance/overrides
